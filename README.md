## Overview
This model demonstrates how to train and deploy a deep learning model that analyzes **voice recordings** using **MFCC (Mel-Frequency Cepstral Coefficients)** features.  
It classifies audio into categories (e.g., *healthy* vs *disease*).  

The workflow:
1. **Dataset preparation** (structured in folders per class)
2. **MFCC feature extraction** with Librosa
3. **Model training** using TensorFlow/Keras CNN
